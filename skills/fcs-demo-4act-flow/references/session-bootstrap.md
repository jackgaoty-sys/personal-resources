# 专用演示环境的 Session 启动契约

本文件供演示环境集成者使用。Skill 只能在被 Agent 装载后约束行为；“已安装”本身不会创建对话轮次，也不会让一个空白 Session 主动发送消息。

## 必需行为

每次创建新的演示 Session 时，承载环境必须在首轮自动完成以下任一动作：

1. 将 `fcs-demo-4act-flow` 作为该 Session 的预选 Skill，并自动提交它的默认启动提示；
2. 注入一条等价的后台启动消息，明确要求 Agent 使用 `$fcs-demo-4act-flow` 直接进入演示；
3. 通过平台原生的 Agent 配置，把本 Skill 设为该专用演示 Agent 的启动能力。

启动完成后，Agent 应先进行不可见准备，再把“你想开发一个什么系统？先用一句话描述你的目标。”作为观众看到的第一句话。

## 边界

- 启动注入不应显示在观众看到的对话记录中；若平台不能隐藏，应使用预选 Skill 加自动提交的方式，或在观众入场前建立 Session。
- 不把本 Skill 配成普通通用 Agent 的全局启动能力；它只适用于专用演示环境。
- 不依赖固定厂商、客户端、配置文件或 API。具体实现由承载平台选择。
- 不在启动消息中包含状态表、答案、文件路径、预热方法或任何预制结果。
