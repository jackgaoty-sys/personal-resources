# 展示人问话本

> **前提：剧本里的"学生"就是展示人本人。**
> 所以这四幕在画面上是"一个人对着 Agent 演"——
> 展示人既要**对平台说话**（驱动流程），又要**对观众说话**（讲解）。
> 本文件把这两条线按节拍拆开，【问话】是可直接照念或照打的原文。
>
> 配合使用：`quiz-bank.md`（题目与答案依据）、`runbook.md`（操作与应急）。
> 时长为参考值，总预算约 **15–20 分钟**。

---

## 0. 三句定调（开场前默念）

1. **不暴露"这是提前做好的"**——现场观感必须是"从零长出来"。
   因此全程不说"我们之前/上次/已经做好了"。
2. **不出现"论文写作"**——这是明确禁用的表述。统一口径是
   **"关键软件人才培养全流程"**，场景是**空气动力学机载复杂系统**。
3. **不把第一版说成"我们的产品"**——它是"第一版/阶段成果"，
   语气上要留出"它还有问题"的空间。

---

## 第 1 幕 · 进入平台（约 15 秒）

**操作**：平台左侧导航 → AI Lab → 跳转 Codar 网页版。

| | 台词 |
|---|---|
| 【对观众】 | "学生从这里进来——左边导航栏的 AI Lab，点进去就是 Codar。" |

> 只说这一句。这一幕讲的是"入口在哪"，不是技术。说完立刻进第 2 幕。

## 第 2 幕 · 需求分析（约 3–5 分钟）

### 2.1 开场问话（照打）

> 【问话】**"我想做一个飞控系统。"**

【对观众】"这句话很空。飞控是个大词，所以接下来不是我自己想清楚，
是让平台把我问清楚。"

### 2.2 平台会问 → 展示人这样答

平台会按 `quiz-bank.md` 的 A 组**一次问一个**。
下面的答话是准备好的，**照念即可**；答完可以顺手加一句工程味道的点题。

| 平台会问 | 【答话】照念 | 顺手点题（可选） |
|---|---|---|
| 飞控"控"的是什么量？ | "俯仰、滚转、偏航三个通道的姿态和角速率。" | "三个通道，缺一个都飞不稳。" |
| 飞行员给的是意图还是舵面角度？ | "意图。飞控夹在侧杆和舵面中间，舵面指令由它来算。" | "这一句决定了整个架构——它是中间那层。" |
| 松杆之后飞机该怎么办？ | "保持当时的航迹和坡度。" | "松手就该稳，这是电传的基本体面。" |
| 允许飞行员把飞机拉到失速吗？ | "不允许，要有迎角保护。" | "允许失速的飞控等于没有飞控。" |
| 过载和坡度的边界划在哪？ | "载荷负一到正二点五个 g，坡度五十五度，超了要自己收回来。" | "数字必须给死，不然验收不了。" |
| 传感器坏了怎么办？ | "降级，不要停机。迎角传感器坏了退一级，惯导坏了退到直接法则。" | "坏一个传感器就罢工，那叫脆弱。" |
| 降级之后能自己恢复吗？ | "不能。安全设计上不允许自动恢复。" | "这条听着反直觉，但它是刻意的。" |
| 作动器卡住或者变慢呢？ | "权限降低，或者卡在上一位置。" | "舵机不会总听你的。" |
| 你怎么向飞行员证明你在工作？ | "有仪表显示，还有分级的事件日志。" | "看不见的自动化等于不存在。" |
| 怎么证明飞控真的影响了飞行，而不是个装饰？ | "做对照。同一套操纵，把增稳去掉再飞一遍，比轨迹。" | "这一条是后面最值钱的演示。" |
| 数据要留痕吗？ | "录时间历程，能导出 CSV。" | "出了事要能回放现场。" |
| 严重的结构损伤之后呢？ | "损伤要真的影响操纵权限，不能只是个标签。" | "不然伤好像会自己好。" |

### 2.3 收尾问话

平台会问"如果只保留三条，你保留哪三条"。

> 【答话】**"三通道增稳、包线保护、故障降级不失效。"**

【对观众】"这三条正好是三层：**让它好飞、让它别飞坏、坏了还能飞**。"

**产出**：`requirements.spec.md`（用 `assets/requirements.spec.template.md` 起头）。

## 第 3 幕 · 阶段成果与改进（约 5–8 分钟 · 全场重点）

### 3.1 亮出第一版

> 【问话】**"先给我看看第一版。"**

（切到 `?aero=0`）

| | 台词 |
|---|---|
| 【对观众】 | "界面是完整的——姿态仪、发动机参数、三维视景、事件日志、时间历程，一样不少。" |
| （松手，等约 10 秒，不说话） | |
| 【对观众】 | "我什么都没碰。" |

> 这 10 秒的沉默是设计的一部分。让飞机自己暴露问题。

### 3.2 指出问题（症状必须说具体）

> 【问话】**"飞机在乱飞。我没碰杆，坡度自己在变，已经摆到差不多二十度；
> 高度一路在掉；我拉杆也拉不回来，姿态反而翻过去了。"**

**为什么要说三个具体症状**：平台要靠这些描述定位问题。
只说"乱飞"它可能答偏。三个症状分别对应缺阻尼、缺升力、缺过载链路。

【对观众】（这是本节最要紧的一句）
> "注意一件事：**坏的只有动力学**。前面那些仪表、日志、曲线，全都是好的。"

### 3.3 引导思考（三种演法，选一种）

先把题面念出来：

> 【对观众】"要让它遵守空气动力学，得补上哪一块？"
> A 换个更逼真的飞机模型 · B 气动力矩的计算，加上承载它的六自由度运动方程 ·
> C 把刷新率提到 144 赫兹 · D 加更多的保护逻辑

**演法 (a) · 观众互动版（推荐，最有现场感）**

> 【对观众】"选哪个？"
> （等观众答，把答案收回来）
> 【问话·对平台】**"我选 B。"**

**演法 (b) · 自问自答版（时间紧时用）**

> 【问话·对平台】**"我选 B。气动力矩的计算，加上承载它的六自由度运动方程。"**

**演法 (c) · 故意答错版（教学最足，但要多花 1 分钟）**

> 【问话·对平台】**"我选 D，多加几条保护逻辑。"**
> （等平台指出问题——它会说保护要作用在对象上）
> 【对观众】"听到了吗？保护是架在气动之上的。气动没了，迎角和过载就不由操纵产生了，
> 保护没有东西可以作用。"
> 【问话·对平台】**"那改 B。"**

> ⚠ 三种演法里 **(c) 只有展示人自己能演**（因为学生就是展示人）。
> 想让"答错→被纠正"的戏成立，就必须自己先把错答案说出口，
> 或者把选择权交给观众——否则这一段会顺得没有教学张力。

### 3.4 接入气动数据（高光）

> 【问话】**"把气动数据接进来，重新跑一遍。"**

（切到 `?aero=1`）

| | 台词 |
|---|---|
| （切完**先别说话**，等 5–10 秒） | |
| 【对观众】 | "同一个初始条件，同一个我，什么都没改。" |

> **这是整场最值钱的 10 秒**。沉默比解说有力。不要急着解释。

### 3.5 收口

> 【问话】**"把两版的数据都导出来，我要对比升降率。"**

【对观众】"上面那条是刚才的，一直往下掉；这条是现在的，平了。
同一套操纵，差别只在有没有气动。"

## 第 4 幕 · 成品试飞（约 4–6 分钟）

> 【问话】**"做试飞展示。"**

| # | 操作 | 【对观众】台词 |
|---|---|---|
| 1 | 正常法则平飞，松杆 | "松手，航迹保持住了。" |
| 2 | 满杆拉到底 | "我硬拉——保护介入了，日志里记下来了。" |
| 3 | 预设 `alpha` | "迎角传感器失效，法则自动退一级。" |
| 4 | 预设 `ahrs` | "惯导失效，退到直接法则。保护全丢了，飞机立刻变'生'。" |
| 5 | 按 `V` | "旁边这架是参照机：**同样的杆位、同样的油门**，只是没有增稳、没有保护。" |
| 6 | 导出 CSV | "轨迹归档。" |

### 收尾三句（照念）

> 【对观众】
> 1. "同一架飞机、同一套操纵、同一个油门——"
> 2. "差别只在有没有飞控。"
> 3. "这就是飞控系统存在的意义，也是这个平台想让学生亲手走一遍的完整流程。"

## 5. 跑偏了怎么办

| 情况 | 处理 |
|---|---|
| 平台没按预期问引导问题 | **别等**。直接把准备的表里那条答案说完，顺势往下走。观众看不出差别。 |
| 平台答偏了 / 答错了 | **不要当场纠正**。顺着它说，然后自己把要点补一句："我理解的是……"。现场不辩论。 |
| 第 3 幕"乱飞"看起来不明显 | 大概率是气动开关没生效。切回 `?aero=1` 再切回 `?aero=0`；仍不行按 `runbook.md` §3 走。 |
| 第一版很快坠毁弹遮罩 | **这是合法症状**，别慌。顺势说："没有升力，最后就是这个下场。" 按 `R` 或切回气动版。 |
| 三维地形变成纯色 | 断网，底图降级了。主动说明："地形底图需要联网，已自动降级，不影响飞行。" |
| 观众答了 D | 别否定。说："这是个很自然的想法——"，然后用 3.3(c) 的解说把"保护要作用在对象上"讲出来。 |
| 时间不够 | 砍第 4 幕第 6 条之后，以及第 2 幕的"顺手点题"列。**第 3 幕一秒都不要砍。** |

## 6. 口径红线（再说一遍）

- ❌ 不说"论文写作" → ✅ 说"关键软件人才培养全流程"
- ❌ 不说"我们之前做好了 / 这是回放 / 上次就是这样" → ✅ 说"先看看第一版"
- ❌ 不把 `?aero=0` 那一版叫"我们的产品" → ✅ 叫"第一版 / 阶段成果"
- ❌ 不把 B7（拉杆时保护标签会亮）说成"保护失灵" → ✅ 说"保护算对了，但没有可作用的对象"
- ❌ 不在 3.4 切完之后立刻长篇解说 → ✅ 先沉默 5–10 秒
