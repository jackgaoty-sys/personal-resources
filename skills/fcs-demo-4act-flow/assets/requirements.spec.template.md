## 1. 一句话目标

> 做一个夹在"侧杆"和"舵面"之间的________，让飞行员给________，
> 由飞控算出________，并保证飞机不飞出________。

填空参考答案：
`闭环飞行控制系统` / `操纵意图` / `舵面指令` / `安全包线`

---

## 2. 控制通道

| 通道 | 控制量 | 松杆行为 |
|---|---|---|
| 俯仰 | 载荷因数 / 航迹角 | 保持当时航迹角（FPA HOLD） |
| 滚转 | 滚转角速率 / 坡度 | 保持当时坡度（BANK HOLD） |
| 偏航 | 侧滑角 + 脚舵 + 荷兰滚阻尼 | 协调转弯 |

## 3. 包线保护（**必须写数字**）

| 项目 | 指标 | 可测判据 |
|---|---|---|
| 迎角保护起效 | ____ ° | 超过后不再允许继续加载荷 |
| 迎角硬上限 | ____ ° | 无条件强制推出 |
| 俯仰姿态限制 | ____ ° ~ ____ ° | 超限只允许回中方向 |
| 坡度限制 | ____ °（回退到 ____ °） | 按住滚转杆也绕不过去 |
| 载荷限制 | ____ g ~ ____ g（结构上限 ____ g） | 硬限无条件生效 |
| 速度上限 | ____ kt | 超速告警 |

参考值（fcs-demo 实测）：12 / 15 / -15~25 / 55→30 / -1.0~2.5（结构 3.8）/ 160

## 4. 法则与降级

| 状态 | 触发条件 | 后果 |
|---|---|---|
| NORMAL | 正常 | 全保护 + 自动配平 |
| ALTERNATE | α 传感器失效 | 部分保护失效，滚转权限降低 |
| DIRECT | AHRS 失效 | 杆位直连舵面，**保护全部丢失** |

**不可逆性**：法则只能变差，**不能自动恢复**。 ☐ 已确认这是设计意图（而非缺陷）

## 5. 故障处置

| 故障 | 期望行为 |
|---|---|
| α 传感器失效 | 降级 ALTERNATE |
| AHRS 失效 | 降级 DIRECT |
| 升降舵作动器降级 | 权限降至 ____ % |
| 副翼卡阻 | 卡在上一位置 |
| 方向舵卡阻 | 卡在上一位置 |

## 6. 结构损伤

- 损伤等级：完好 / 轻损 / 结构超限 / 坠毁
- 要求：损伤**必须真正影响飞行**（衰减舵面权限与作动速率），不能只是标签。

## 7. 人机界面

- ☐ PFD（姿态、空速、高度、升降率、航向）
- ☐ ECAM（发动机与告警）
- ☐ 模式与保护状态提示（法则、保护标签）
- ☐ 分级事件日志（信息/模式/阶段/硬件/注意/故障，可回溯）
- ☐ 时间历程条带图
- ☐ 3D 外部视景（多视角）

## 8. 可观测性与数据

- 时间历程录制：____ Hz，覆盖 ____ 秒，可导出 CSV
- 导出列必须含：高度、空速、升降率、迎角、侧滑角、过载、姿态、三通道指令、配平、法则、油门

参考：60 Hz / 600 秒

## 9. 动力学模型（第 3 幕的伏笔）

- ☐ 6-DoF 运动方程
- ☐ 气动力矩（升力/阻力/侧力及其力矩）
- ☐ 机型气动数据表
- ☐ 发动机与螺旋桨模型

> **第 3 幕要用到这一节**：如果这里打了勾，而飞机在实际表现上做不到，
> 就是"阶段性成果"与需求之间的差距。这正是学生要指出来的 bug。

## 10. 验收标准（必须可测）

| # | 验收项 | 判据 |
|---|---|---|
| 1 | 能配平到平飞 | 初始 4500 ft / 110 kt，松杆后高度波动 < ____ ft |
| 2 | 飞控真的影响飞行 | 同一杆位/油门，有增稳 vs 无增稳的轨迹可辨（参照机对照） |
| 3 | 包线保护有效 | 满杆拉到底不越限，且日志出现保护介入 |
| 4 | 降级链条正确 | 注入对应故障后法则按表降级，且不自动恢复 |
| 5 | 损伤接入飞行 | 标记"结构超限"后操纵权限/响应可见下降 |
| 6 | 数据可留痕 | 能导出 CSV 且列齐全 |
| 7 | 动力学真实 | 高度不因"没有升力"而单调下降；操纵与响应符合气动规律 |
