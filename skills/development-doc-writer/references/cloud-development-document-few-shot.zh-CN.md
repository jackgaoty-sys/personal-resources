# 示例：Orion Cloud 与 Main 集成分支开发说明

> **读者**：负责 Orion Web / Cloud Agent 开发、测试与发布的同事
> **日期**：2026-01-15（示例）
> **状态**：Cloud 长期分支已吸收已验证的 Main 更新；核心隔离回归通过，生产存储仍待验收
> **工作分支**：`cloud-integration-example`
> **上游基线**：`main@abc1234`（合成值）
> **发布状态**：测试环境已部署 `release-example-a`；尚未完成生产发布
> **Git 状态**：存在未提交修改；未 push

## 1. 一句话理解本分支

本分支复用 Main 的通用产品能力，同时在身份、状态、执行环境和发布产物上保持 Cloud 隔离；它只吸收 Main 更新，不反向合入 Main。

当前版本适合开发联调和测试环境验证，但不能因本地自动化通过就视为生产验收完成。

## 2. 集成边界

| 维度 | Main 提供 | Cloud 分支处理 |
|---|---|---|
| 用户身份 | 通用会话协议 | 所有受保护 API 先校验 Web Session，再派生租户上下文 |
| 状态存储 | 通用数据模型 | 开发环境按租户隔离；生产数据库迁移单独验收 |
| 工具执行 | 通用工具注册 | 写文件、命令和浏览器操作只进入 Remote Sandbox |
| 前端功能 | 共享页面与 Marketplace | 前端根据后端 Capabilities 显示、禁用或隐藏功能 |

### 2.1 不可突破的边界

1. 所有开发、合并和冲突处理只发生在 Cloud 专用分支。
2. Sandbox 不可用时必须明确失败，不能回退到 API 宿主机执行。
3. 未完成租户 Adapter 的客户端能力不得通过开发开关进入生产配置。

### 2.2 长期同步方向

```text
main 的已验证更新
        │ 人工同步并回归
        ▼
cloud-integration-example
        │ 独立开发、测试和发布
        └── 不反向合入 main
```

## 3. 当前架构与运行路径

```text
浏览器
  │ 登录 + HttpOnly Session
  ▼
Cloud API
  ├── 身份与租户校验
  ├── 租户 Store
  └── Agent Core
        ├── 模型调用 → 租户 Provider
        ├── 文件/命令 → Remote Sandbox
        └── 快照 → Object Storage
```

| 环境 | 用途 | 约束 |
|---|---|---|
| 开发容器 | 编译、单测、前后端联调 | 工具链保留在容器内 |
| 测试服务器 | 真实登录和外部服务联调 | 使用独立数据目录与可回滚版本 |
| 生产环境 | 正式流量 | 必须通过生产存储、权限和容量验收 |

## 5. 已完成的开发工作

### 5.1 Cloud 身份与会话隔离

- **问题**：部分直接 ID 接口只校验登录，未校验资源归属。
- **修改**：所有读取、派生、修改和删除操作先按当前租户查询资源；非所有者统一返回 404。
- **验证**：双 Session 自动化覆盖读取、修改、删除与派生操作。
- **效果**：其他租户不能探测资源是否存在，也不能改变其状态。

### 5.2 Runtime Capabilities

- **目标**：避免前端各页面散布 Cloud 模式判断。
- **修改**：后端统一返回业务能力、宿主能力和依赖状态；前端按字段控制入口和请求。
- **验证**：开启、关闭和依赖缺失三种配置均通过路由与页面测试。
- **限制**：Capabilities 只声明能力，不能替代后端授权和租户校验。

### 5.3 Sandbox 与工作区

- **问题**：某文件工具仍可能读取宿主路径。
- **修改**：文件读取、补丁和写回全部通过 Sandbox Workspace；初始化失败时 fail-closed。
- **验证**：真实 Sandbox round-trip、宿主目录不变和失效实例恢复测试通过。
- **剩余工作**：生产模板的并发、超时和成本指标尚未验收。

## 7. 生产启动约束

```bash
APP_MODE=cloud \
APP_STORAGE_MODE=sql \
APP_RUNTIME_AUTO_INSTALL=false \
./example-app serve
```

- 服务只读取部署 Secret；不得把 Secret 写入镜像、Compose 或日志。
- 数据目录和发布目录分离；版本切换不能覆盖持久数据。
- 生产默认关闭未完成租户化或仍依赖宿主机的能力。
- 健康检查成功不等于模型、Sandbox 和存储业务链路通过。
